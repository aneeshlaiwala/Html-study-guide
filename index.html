BUILD 1

Lists

Whether it is the minutes of a meeting, a list of items, or the table of contents of a document, you will find the use of a list in all.

A list is the most efficient way of presenting information in a precise manner. It helps in making important points stand out more clearly, thereby grabbing a visitor's attention. A list can be defined as an ordered list or an unordered list.

♘ THE ONE QUESTION THAT DECIDES IT

Ask yourself: if I shuffle these items, does anything break? Chess moves — 1. e4, 2. Nf3 — break if you swap them, so they need an ordered list. Your bag of pieces — rook, bishop, knight — does not care about order, so that is an unordered list. That single question answers every list question in the paper.

⚠ START IS ALWAYS A NUMBER — EVEN FOR ROMAN LISTS

Your textbook asks students to fix this exact line:

The error is start = 'iii'. The type decides what the markers look like, but start is always counted as a plain number. To begin at the third Roman numeral you write <ol type = "i" start = "3"> — and the list then shows iii, iv, v.

The <marquee> tag

The <marquee> tag helps in displaying the scrolling text on the web page.

⚠ THE THING EVERYONE GETS WRONG

Marquee confuses students because of one sentence in the textbook: "This tag is not a part of HTML5." People read that and think it does not work, or that they must not use it.

Both readings are wrong. It still works in every browser, it is in your notes with a full example, and it has been asked in the review paper. Learn it properly. Just also remember the sentence, because "Which tag is not a part of HTML5?" is a one-mark question.

The <img> tag

The <img> tag is used to add images in an HTML web page. It is an empty tag and requires different attributes to be specified with it. These attributes tell the browser how to layout the page so that the text can flow properly around the image.

🧩 EMPTY TAG vs CONTAINER TAG — THE CHEST ANALOGY

In Minecraft there are two kinds of block. A torch is just placed — it holds nothing, so there is no "closing" it. A chest is opened, filled, and closed again.

Empty tags are torches: <img>, <br>, <hr>, <input>. You place them and move on. Container tags are chests: <a>…</a>, <table>…</table>, <form>…</form>. You open them, put something inside, and close them. Writing </img> is trying to close a torch.

Linking web pages

A website consists of a number of web pages that give you access to the related information. HTML renders a powerful feature of linking these web pages together.

This feature is called Hyperlinking. Using hyperlinks, one can open any linked web page on the internet in no time. When you hover the mouse pointer over a link, it will turn into a little hand.

🧩 THINK OF IT AS A PORTAL

A hyperlink is a nether portal. One page is the overworld, another is the nether, and the anchor tag is the obsidian frame you build between them. Get one block of the frame wrong — a wrong file name or the wrong folder — and stepping in does nothing at all.

The anchor <a> tag

In HTML, the anchor <a> tag is used to mark the text as a hyperlink, which a user can click to display the document anchored to it. Being a container tag, it requires the closing tag </a> to mark the end of the text or image.

This tag is generally used to specify the following:

  • The text or image that is clicked to activate the link.
  • The address that will be opened using the defined link.

You can use hyperlinks to jump from one section to another within the same web page, to link to another page within the same website, or to link to another page or website anywhere on the web.

⚡ href vs src — THE PORTKEY AND THE PHOTOGRAPH

These two get swapped over in exams more than any other pair, so tie them to two different ideas.

src = "show me this here". It is a photograph in a frame on the wall. The picture is fetched and displayed right there on the page. You do not go anywhere.

href = "take me there". It is a portkey: touch it and you are transported somewhere else. Nothing is displayed — you travel.

💡 SO WHEN BOTH APPEAR TOGETHER

A clickable image uses both, and each keeps its own job:
<a href="about.html"><img src="logo.jpg"></a>
The img src shows the logo here. The a href takes you there. If the two values are swapped, the browser tries to display a web page as a picture and travel to a photograph — so nothing appears and nothing works. That is exactly the error the review paper sets.

Tables

Tables are extremely popular on the web because they are flexible and an attractive way of presenting information in the form of rows and columns.

♜ A CHESSBOARD IS A TABLE

Eight rows, each holding eight squares. You never place a piece "in a row" — you place it in a square, and the square lives inside a row. That is exactly the nesting HTML wants: cells inside rows, rows inside the table.

It also explains why the address of a chess square is two things — a letter and a number, e4, g7. One fact is never enough to find a square, and one fact is never enough to need a table.

How to actually build one, in your head

Once you know you need a table, the mistake is trying to see the whole grid at once. You cannot. A browser builds a table one row at a time, left to right — and so should you.

🧩 THINK LIKE A MINECRAFT BUILDER

You do not build a wall by placing every block at once. You lay one row of blocks, then the next row on top, then the next. A table is exactly that.

Each <tr> is one row of blocks. Each <td> inside it is one block in that row. You never place a block floating in the air — it always belongs to a row. That is why a <td> can never sit directly inside <table>.

The four-step method

1
Count your columns. Look at your data and ask how many facts per thing. Three facts means three cells in every row. Write that number down — it never changes.
2
Write the heading row first. One <tr> holding that many <th> cells. These are the column labels.
3
Add one <tr> per thing. One row per country, per player, per item. Each row holds the same number of <td> cells as your heading row.
4
Count again. Every row must have the same number of cells. If one row has four cells and the rest have three, the table goes crooked — and that is the commonest reason a table "looks broken".

Making one cell cover two — colspan and rowspan

Sometimes a table is not a perfect grid. One title might stretch across the whole top, or one name might cover two rows. That is what these two attributes are for.

🧩 THE MINECRAFT SLAB ANALOGY

Normally every block takes one space. But some blocks are double-wide — place one and it fills two spaces at once, so you place one fewer block in that row.

That is exactly what colspan="2" does. The cell eats two columns, so that row needs one fewer <td>. Forgetting to remove the spare cell is why the table suddenly sticks out on one side.

The three gaps, and why they get confused

Three different properties all add space to a table, and students mix them up constantly because the names sound alike. They control three different gaps.

🎒 THE CLASSROOM ANALOGY

Picture a classroom of desks, each with a student sitting at it.

  • Padding is the space between the student and the edge of their own desk. Elbow room. It happens inside one desk.
  • Border-spacing (or cellspacing) is the gap between the desks themselves. Aisle room. It happens outside the desks.
  • Border-collapse decides whether neighbouring desks are pushed together so their edges become one shared edge, or kept apart with their own separate edges.

The textbook definition, word for word

✎ LEARN THIS PARAGRAPH

The term VIRUS stands for Vital Information Resources Under Seize. It is a program or programs that disrupts the normal functioning of a computer. A virus infects or destroys data. It enters a computer without the permission or knowledge of the user.

The essential resources of a computer — like memory, processing speed, data, and programs — are hampered when a virus spreads into the system.

What it actually is

  • A computer virus is a software program or a "piece of code" that can make copies of itself and attaches itself to other programs or files.
  • A virus may or may not be destructive.
  • In the same way that biological viruses enter our body and attack certain cells, computer viruses enter a computer system without the permission or knowledge of the user.
  • Almost all viruses are attached to an executable file (a file with a .exe extension) and will not infect the computer unless you run or open the malicious program.
🧠 THE SENTENCE THAT EARNS MARKS

"A virus needs a host file and a human action." Almost every "how is a virus different from a worm" answer starts there. A virus sits attached to a file and waits; nothing happens until somebody opens or runs it.

🧺 VIRUS vs WORM — THE MIMIC AND THE SLIME

Think of two very different monsters.

A virus is a mimic. It disguises itself as an ordinary chest and sits perfectly still. It cannot chase you. It does absolutely nothing until a player walks up and opens it. No human, no attack.

A worm is a slime. Hit it once and it splits into two, and those split again. Nobody has to do anything — it multiplies on its own until the whole room is full and the game slows to a crawl. That is exactly what a worm does to memory.

Each one in your notes' own words

Program File Virus

  • This type of virus infects the executable files or programs such as those with extension like .com, .exe, .ovl, .drv, .sys (your notes also list .DLL and .SCR).
  • It gets loaded in memory during the execution. The virus remains active in the memory and infects files and other programs on the disk with the intention of causing permanent damage or making them unreadable.
  • The virus becomes active when the infected file is executed.

Ex: Sunday and Cascade

Boot Sector Virus

  • This type of virus infects the boot sector of a hard drive.
  • A disk or hard drive consists of sections known as sectors. The first sector is called the boot sector.
  • It carries the master boot record which is responsible for loading the operating system.
  • The boot sector virus becomes active at the time of booting the machine.

Ex: Disk Killer, Stoned virus etc.

Macro Virus

  • A macro is a set of commands written by the user to be executed later.
  • This virus infects the files created using applications like Word, Excel and PowerPoint.
  • When the infected document is opened the virus gets loaded into the main memory.
  • Once it is active on the computer, every document you produce will be infected.

Ex: Melissa A, Relax, Bablas

💡 THE GIVEAWAY

If a question mentions a document — a Word file, a spreadsheet, a presentation — and says everything the person makes afterwards is also infected, that is a macro virus every time.

Multipartite Virus

  • It is a hybrid of a boot sector and program file virus.
  • The virus first enters through some infected media and resides inside memory and then moves into the hard drive, infects the boot sector and starts spreading itself in the system by infecting the executable files.

Ex: Invader, Flip, Tequila

🧥 MULTIPARTITE — THE TWO-FRONT ATTACK

Most viruses attack one thing. A multipartite virus attacks two at once — the boot sector and the program files. It is the villain who comes at you on the ground and from the air at the same time, so blocking one route does not save you. That is why hybrid is the key word in its definition.

Polymorphic Virus

  • This type of computer virus exhibits itself in different forms every time it infects a file and changes its binary pattern to avoid detection by an antivirus program.

Ex: Elkern, Marburg, Satan Bug

💡 REMEMBER IT BY THE WORD

Poly means many and morph means shape. A polymorphic virus is the shape-shifter — many shapes, so the antivirus cannot recognise it.

🤐 POLYMORPHIC — THE SHAPE-SHIFTER ON THE WANTED POSTER

An antivirus catches viruses the way police catch a thief: by comparing what it finds against a book of wanted posters — the virus database of known file patterns.

A polymorphic virus changes its face before every single robbery. The poster is accurate, and useless. This is precisely why the answer to "why must an antivirus be updated?" is about new patterns — the book of posters has to keep growing.

Network Virus

  • This type of virus rapidly spreads through LAN or internet.
  • Network viruses multiply through shared resources, i.e. shared drives and folders.
  • When the virus infects a computer, it searches through the network to attack its next potential prey. When it finishes infecting that computer, it moves on to the next and the cycle repeats itself.

Ex: Nimda, SQL Slammer

The malware family

The term malware is made up of two words — malicious and software.

It is a generic term used for such programs that enter into a computer and damage it without the user's knowledge. Malware not only interrupts the normal functioning of a computer, but also steals important information. Some of these include worms, trojan horses, spyware, ransomware, rootkits and backdoors.

💡 THE ETYMOLOGY IS THE DEFINITION

Malicious + software = malware. If a question says "what is malware", opening with that split earns the mark immediately, then add "a generic term for programs that enter a computer and damage it without the user's knowledge".

⚠ THE WORD THAT TRIPS PEOPLE UP

A virus is one kind of malware, not the opposite of it. Malware is the whole family; virus, worm, Trojan and spyware are members of it. If a question says "name the type of malicious program", you may answer with any family member — so read the clues and pick the right one.

Worms

⚠ A WORM IS A SUB-CLASS OF A VIRUS

The textbook says a worm is similar to a virus in design and is considered to be a sub-class of a virus. That sounds like it contradicts "worms and viruses are different" — it does not. They are related in design, but they differ in how they spread: a virus needs a human, a worm does not. Say both and you cannot be marked down.

  • A worm is similar to a virus in design and is considered to be a sub-class of a virus.
  • Unlike a virus, it is a self-replicating program — it has the capability to spread without any human intervention.
  • Due to this self-replicating nature, the end result in most cases is heavy consumption of system memory (or network bandwidth), causing web servers, network servers, and individual computers to stop responding.
  • It consumes a lot of memory space in replication.
  • Once a computer has been infected by a worm, its processing speed slows down, it works unexpectedly, and halts other tasks.
  • A computer worm can spread itself from one computer to another through the replication process.
  • Blaster Worm was the popular computer worm that spread through Microsoft's operating system.
  • The Morris worm / Internet worm was one of the first computer worms to be distributed over the internet.

Trojan Horses

  • The name Trojan has been derived from the wooden horse used by the Greek army to conquer the city of Troy.
  • The Trojan horse at first glance will appear to be useful software but actually damage the computer once it is installed.
  • Users on the receiving end of a Trojan horse are usually tricked into opening them.
  • Trojans have different behaviour once they gain access into the system — for example some Trojans change the desktop by adding silly desktop icons, or prevent applications from running, especially antivirus applications.
  • Trojans are also known to create a back door on a computer that gives easy and unauthorised access to malicious users, thus allowing your confidential or personal information to be compromised.
  • Unlike viruses and worms, Trojans do not reproduce by infecting other files nor self-replicate. They require human action to run.

Examples of Trojan horse: Beast and Zeus.

💡 THE STORY IS THE DEFINITION

The Greeks hid inside a gift. A Trojan hides inside something that looks useful — a free game, a "PC speed booster". If a scenario says the person installed a program that promised to help, the answer is Trojan Horse.

🎃 TROJAN — THE GIFT NOBODY CHECKED

The reason the Trojan Horse worked was not that it was strong. It was that the people of Troy carried it inside themselves. The walls held; the invitation did not.

That is the whole lesson of this malware. A Trojan cannot break in, cannot spread itself, and cannot copy itself. Its only weapon is persuading you to install it. Which is why the precaution is never "buy a better antivirus" — it is download only from a trusted source. Do not wheel the horse in.

Spyware

  • Spyware is a type of malware that monitors a user's activity and sends the collected information back to a hacker.
  • Spyware does not have any infection mechanisms of its own. It is usually dropped by trojans (and also by viruses and worms). Once dropped, it installs itself on the victim's computer and remains silently to avoid detection.
  • Spyware programs can collect various types of personal information, such as internet surfing habits, visited web pages, passwords, and even credit card numbers.
  • While doing so, they consistently transmit the information in the background to someone else who will either sell the information to another party or use it for advertising/marketing purposes.
  • Sometimes, they also change the computer's settings, which results in slow connection speed, and wrong functionality of the other programs.

Example of spyware is Pegasus Spyware.

🕵 SPYWARE — THE INVISIBILITY CLOAK

Spyware is the one malware that is trying not to be noticed. Everything else announces itself — files corrupt, the computer slows, fake warnings pop up. Spyware does the opposite: it puts on a cloak and watches.

It has no way of getting in on its own — it is carried in by a Trojan, like a passenger. Then it sits silently, notes down the passwords, and sends them out of the castle. In a scenario question, the giveaway is always that the damage is discovered somewhere else: an email read from another city, money gone from an account. The computer itself seemed fine.

⚠ THE ASSERTION-REASON TRAP

The last paper said: "Assertion: Spyware secretly collects information without permission. Reason: Spyware is a harmless program that protects user privacy." The assertion is true, the reason is false — spyware is the opposite of harmless. The answer was "(A) is true and (R) is false". Watch for reasons that flatly contradict the assertion.

Sweeper

  • Sweeper is a form of virus that looks like an antivirus program and the user unintentionally downloads it.
  • This virus comes from a malicious website to install the malicious code on the computer.
  • It controls the browsing activity of the user and changes system files without the user's knowledge.
  • Once installed, it creates a variety of harmless, fake malware files in the computer, which get automatically started when the user logs in to Windows.
  • On running, it performs a scan and prompts security alerts by displaying a list of fake malware files to scare the user into thinking that his computer is infected.
  • One should ignore these alerts and make use of proper steps to remove the malicious code.

Antivirus & safety

Antivirus software is a program designed to identify, prevent, and remove malware from your computer.

What antivirus software does

  • It helps protect your system by detecting viruses and other malicious threats and preventing them from infecting or damaging your files.
  • With hundreds of new viruses being developed every hour, antivirus software developers frequently release updates to help their programs recognize the latest threats.
  • These updates are typically downloaded from the Internet, so it is essential to have an Internet connection to update an antivirus software.
✎ WHY "UPDATE" IS THE MAGIC WORD

Almost every safety answer in this chapter contains the word updated. An antivirus that is installed but out of date cannot recognise new threats, because new ones appear every hour. When a question asks what someone did wrong, "the antivirus was not updated" is very often the mark.

✎ THE THREE TASKS AN ANTIVIRUS PERFORMS

The textbook lists exactly three. This is a ready-made three-mark answer.

  1. It scans the computer files to look for known virus from the virus dictionary and tries to remove them.
  2. It identifies suspicious behaviour of any computer program, which may indicate infection.
  3. It scans incoming emails, which might contain virus in the attachment.

Working of an Antivirus

All antivirus software operate on similar principles. There are two main components in an antivirus.

ComponentWhat it is
Virus databaseA list of file patterns, which are used to identify a virus.
Scan engineScans files and compares them with the pattern files to verify if there is any infection.

The scan engine runs when the user explicitly activates it, or it can also be set to run automatically any time a file is opened or a program is executed. This is called a real-time scan.

🛡 THE TWO COMPONENTS — THE GUARD AND THE FILE OF FACES

Picture security at a castle gate.

The virus database is the book of known troublemakers — a list of faces and patterns. It knows who to watch for, but it cannot look at anybody.

The scan engine is the guard. It looks at each visitor and compares them against the book. It can look at anybody, but without the book it has no idea who is dangerous.

You need both. And since new troublemakers appear every hour, the book must be updated constantly — a guard with last month's book will wave the newest threat straight through. That is the whole argument for regular updates, in one picture.

💡 REAL-TIME SCAN

A real-time scan runs continuously in the background. It provides maximum protection by scanning the opened or saved files, and displays a notification message when it detects a security risk. This is the "Real-Time Protection" line you see with a green tick or a red warning beside it on an antivirus screen.

Importance of Regular Updates

  • Every antivirus has a virus database that has a list of file patterns used to identify a virus. Therefore, to catch different and new types of viruses, the virus database has to be updated frequently.
  • Simply installing antivirus software in a computer does not guarantee 100% protection, as the installed program may not be able to detect any new virus programs.
  • Frequently updating ensures that the system is always armed and well prepared against all types of virus threats.
  • Protecting your computer is a continuous, on-going activity. Most antivirus companies provide the facility to download the latest updates from their websites.
⚠ THE SENTENCE EXAMINERS LOVE

"Simply installing antivirus software does not guarantee 100% protection." Whenever a question implies that having an antivirus is enough — or asks whether updates matter more than installation — this is the sentence that answers it.

The USB rule

USB questions appear constantly. There is a fixed, correct order — learn it as three steps.

🔌 PLUGGING IN A USB YOU DID NOT CREATE
  1. Update the antivirus first, so its virus definitions are current.
  2. Scan the USB drive with that updated antivirus.
  3. Open it only if no threats are detected. If something is found, quarantine or remove it and do not open the files.

Section F — Short answer

F1. What is a computer virus? Write any two points.

MODEL ANSWERA computer virus is a software program or a "piece of code" that can make copies of itself and attaches itself to other programs or files. It enters a computer system without the permission or knowledge of the user, and it may or may not be destructive.

F2. Write any four symptoms of a virus attack.

MODEL ANSWERAny four of: the computer starts doing things on its own, such as moving the cursor by itself and randomly opening and closing windows; the computer shuts down and restarts frequently; malfunctioning is noticed in several applications; unexpected error messages pop up; the speed of the computer drops; certain drives become inaccessible; menus and dialogue boxes appear distorted.

F4. What is a Trojan horse? Why is it given that name?

MODEL ANSWERA Trojan horse at first glance appears to be useful software but actually damages the computer once it is installed. Users are usually tricked into opening them. F5. What is spyware and what kind of information can it collect?

MODEL ANSWERSpyware is a type of malware that monitors a user's activity and sends the collected information back to a hacker. It has no infection mechanism of its own and is usually dropped by trojans. It can collect internet surfing habits, visited web pages, passwords and even credit card numbers, and transmits this in the background. An example is Pegasus Spyware.

MODEL ANSWERA virus scanning process is used to check a computer or storage device for harmful software such as viruses, malware and other security threats. A red warning symbol indicates that there may be a security problem, such as outdated virus definitions, disabled protection, or a detected threat.

F8. Name any two popular antivirus programs and state what antivirus software does.

MODEL ANSWERAny two of AVG Antivirus, Quick Heal, McAfee, Microsoft Security Essentials, Symantec Norton.
