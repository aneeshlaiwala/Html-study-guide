⚠ THE ONE HABIT THAT SAVES MARKS

HTML is marked on structure, not on looks. Before writing any tag ask two things: does it need a closing tag, and what is it allowed to sit inside? A <td> lives inside a <tr>, which lives inside a <table>. Skip a level and the browser draws nothing at all.

BUILD 1

Lists

Whether it is the minutes of a meeting, a list of items, or the table of contents of a document, you will find the use of a list in all.

A list is the most efficient way of presenting information in a precise manner. It helps in making important points stand out more clearly, thereby grabbing a visitor's attention. A list can be defined as an ordered list or an unordered list.

♘ THE ONE QUESTION THAT DECIDES IT

Ask yourself: if I shuffle these items, does anything break? Chess moves — 1. e4, 2. Nf3 — break if you swap them, so they need an ordered list. Your bag of pieces — rook, bishop, knight — does not care about order, so that is an unordered list. That single question answers every list question in the paper.

Changing the bullets: the type attribute

This attribute specifies the type of numbering or bullet used to mark items in the list. By default, its value is '1' for an ordered list and 'disc' for an unordered list.

Syntax for an ordered list: <ol type = "value"> where value = A | a | I | i | 1

The <img> tag

The <img> tag is used to add images in an HTML web page. It is an empty tag and requires different attributes to be specified with it. These attributes tell the browser how to layout the page so that the text can flow properly around the image.

🤖 WHY THERE IS NO </img>

An empty tag is a single component you plug in, like a sensor on a robot — there is nothing to wrap, so there is nothing to close. Same family: <br>, <hr> and <input>. Writing </img> in an exam is a straight lost mark.

BUILD 3

Linking web pages

A website consists of a number of web pages that give you access to the related information. HTML renders a powerful feature of linking these web pages together.

This feature is called Hyperlinking. Using hyperlinks, one can open any linked web page on the internet in no time. When you hover the mouse pointer over a link, it will turn into a little hand.

🧩 THINK OF IT AS A PORTAL

A hyperlink is a nether portal. One page is the overworld, another is the nether, and the anchor tag is the obsidian frame you build between them. Get one block of the frame wrong — a wrong file name or the wrong folder — and stepping in does nothing at all.

Internal or external?

 Internal linkingExternal linking
DefinitionOne part of a web page is linked to another section on the same pageOne page is linked to another web page or website
You end upOn the same document, further downOn a different document
Typical useA table of contents that jumps to a heading belowA menu that opens another page of the site, or Google

The anchor <a> tag

In HTML, the anchor <a> tag is used to mark the text as a hyperlink, which a user can click to display the document anchored to it. Being a container tag, it requires the closing tag </a> to mark the end of the text or image.

This tag is generally used to specify the following:

  • The text or image that is clicked to activate the link.
  • The address that will be opened using the defined link.

You can use hyperlinks to jump from one section to another within the same web page, to link to another page within the same website, or to link to another page or website anywhere on the web.

The three kinds of href value

The href attribute defines the document to which the link leads.
Syntax: <a href = "value">CLICK HERE </a>

Kind of valuePoints toExampleWatch out for
Absolute URLAnother websitehref="http://www.google.com/"Needs the full http:// part
Relative URLA file within a websitehref="Click.html"Only works if the file is in the same folder
Email addressOpens the mail programhref="mailto:info@kips.in"It is mailto:, never email:
📜 NOTE

The text "CLICK HERE" is called the Hypertext. It is a text that contains links to information on the same web page or some other web page. The browser displays this text as underlined and coloured.

BUILD 4

Tables

Tables are extremely popular on the web because they are flexible and an attractive way of presenting information in the form of rows and columns.

♜ A CHESSBOARD IS A TABLE

Eight rows, each holding eight squares. You never place a piece "in a row" — you place it in a square, and the square lives inside a row. That is exactly the nesting HTML wants: cells inside rows, rows inside the table.

BUILD 5

Forms

One of the most interesting features of the web is the interactive nature of the web pages, which allows the visitors to interact and add some relevant information to it.

Forms are incorporated in web pages so that users can submit their feedback, questions, and concerns to get a more detailed response. A form is a collection of fields of information on a page. It resembles a paper or database form where a user fills the required information. The various fields may contain text boxes, option buttons, drop-down menus, checkbox, password and other elements. These elements are called Form Controls.

🤖 A FORM IS A CONTROL PANEL

The <form> tag is the panel casing. Each <input> is a switch, dial or button bolted onto it. action is the wire that says where the readings go when someone presses Submit. No casing, no wire, no readings.

Section G — Short answer

G1. What is a list? Why is it used on a web page?

MODEL ANSWERA list is the most efficient way of presenting information in a precise manner. It is used because it helps in making important points stand out more clearly, thereby grabbing a visitor's attention. A list can be defined as an ordered list or an unordered list.

G2. Name the two types of images and state the difference between them.

MODEL ANSWERThe two types are inline and external images. An inline image is displayed when the web page is opened and is inserted within a line of text, so it appears automatically with the other content. An external image is not displayed automatically; it is referenced externally and viewed separately by clicking on a link. The <img> tag inserts an inline image while the anchor <a> tag is used for an external image.

G3. What is the purpose of the Alt attribute?

MODEL ANSWERSometimes a browser does not display an image because of a slow connection or an error in the src attribute. The Alt attribute lets you specify text as an alternate to the image, so a description is still shown. Its value can be a text string of up to 1024 characters.

G4. What is hyperlinking? Name and explain its two types.

MODEL ANSWERHyperlinking is the feature of HTML that links web pages together so that any linked web page can be opened quickly. When you hover the mouse pointer over a link, the pointer turns into a little hand. Its two types are internal linking, where one part of a web page is linked to another section on the same page, and external linking, where one page is linked to another web page or website.

G5. Write the three kinds of values the href attribute can take, with one example each.

MODEL ANSWERAn absolute URL, which points to another website, e.g. <a href="http://www.google.com/">. A relative URL, which points to a file within a website, e.g. <a href="Click.html">. A link to an email address, e.g. <a href="mailto:info@kips.in">.

G6. Define: (a) Caption (b) Headings (c) Cell (d) Columns (e) Rows

MODEL ANSWER(a) Caption provides a short description of the table.
(b) Headings are the special cells that act as labels, depicting the type of information in each column.
(c) Cell is the intersection of a column and row.
(d) Columns are the property of an object; also called a Field.
(e) Rows represent the values of all the fields in a table; also called a Record.

G7. Why is <th> used instead of <td> for the first row of a table?

MODEL ANSWER<th> specifies a column heading. It makes the text bold and, by default, centre-aligns it, so the heading row stands out from the data rows created with <td>. Like <td>, it must always be present inside the row tags <tr>.

G8. What is a form? Why are forms incorporated in web pages?

MODEL ANSWERA form is a collection of fields of information on a page. It resembles a paper or database form where a user fills the required information. Forms are incorporated in web pages so that users can submit their feedback, questions, and concerns to get a more detailed response. The various fields may contain text boxes, option buttons, drop-down menus, checkboxes and password boxes, which are called form controls.

G9. Explain the Action and Method attributes of the <form> tag.

MODEL ANSWERAction normally specifies the file or page that the form is submitted to. Its value can be a URL to the script, or an email address defined with the mailto: function. Method specifies that the form information should be posted to the URL given in the action attribute. Its values are Get, the default, used whenever you wish to email the form contents, and Post, used to pass the information to the URL specified in the action attribute.

G10. Explain any four attributes of the <input> tag.

MODEL ANSWERType specifies what type of form control will be added; Text is the default and defines only one line of text. Name gives every control a name to identify it and should be unique. Value specifies the initial value for the element. Size specifies the width of the input field. Maxlength specifies the maximum number of characters for the input field.

G11. What is the function of the Submit and Reset buttons?

MODEL ANSWEROn clicking Submit, the data in all the fields is sent to a server as a series of name and value pairs, where the Name is the name of the form element and the Value is whatever the user entered. The data is sent to the page specified in the action attribute of the <FORM> tag. The Reset button clears the contents and sets default values of all the form elements to the original state and makes them active.

G12. Name any four properties of the <table> tag and write what each controls.

MODEL ANSWERBorder specifies the border width, style and colour of the table and its cells. Text-align sets the horizontal alignment of text in a cell. Border-spacing specifies the distance between the borders of adjacent cells. Border-collapse specifies whether the borders are collapsed into a single border or detached. (Height, width, vertical-align and padding are also acceptable.)

H2. Internal linking and External linking

MODEL ANSWERIn internal linking, one part of a web page is linked to another section on the same page, so the visitor stays on the same document. In external linking, one page is linked to another web page or website, so the visitor is taken to a different document.

H3. Checkbox and Radio button

MODEL ANSWERA checkbox is like a toggle switch where the user can select or deselect one or more items at the same time. A radio button is used when the user has to make a selection of only one among several possible options; radio buttons in the same group share the same name, so selecting one deselects the other.

H4. Get and Post methods

MODEL ANSWERGet is the default value of the method attribute and is used whenever you wish to email the form contents. Post is used whenever you want to pass the information to the URL specified in the action attribute.

H5. border-spacing and padding

MODEL ANSWERborder-spacing specifies the distance between the borders of two adjacent cells, so it controls the gap outside the cells. Padding specifies the space between the border and the content in a cell, so it controls the gap inside a cell.

Section I — Application based

I1. Rohan is making a web page listing the steps to solve a Rubik's cube. He used <ul> and his teacher marked it wrong. Explain why, and name the tag he should have used.

MODEL ANSWERSteps must be followed in a definite sequence, and if the steps are not demonstrated orderly the end result would not be as desired. An unordered list only puts bullets and shows no sequence. He should have used the ordered list tag <ol>, which gives a number to each item.

I2. Meera has placed her photo file in a completely different folder from her HTML file. Write the line of code she should use and explain the rule.

MODEL ANSWERWhen the image file lies in a directory other than the one in which the HTML file is placed, she must specify the full path of the file in the src attribute, for example <img src="C:\Users\MyImages\Pictures\pic1.jpg">. If she wrote only the file name, the browser would look in the same folder as the HTML file, fail to find it, and show the alt text instead.

I3. A school website has a page called results.html inside a folder named exams. The home page is outside that folder. What must be kept in mind while writing the link?

MODEL ANSWERIf the linked HTML document exists in a different folder, the complete path and name of the folder must be specified in the href attribute. So instead of <a href="results.html"> the link should read <a href="exams/results.html">Results</a>. Writing only the file name would make the browser look in the wrong folder and the link would fail.

I4. Aarav's table shows all its data but the cells touch each other and the text is stuck to the border lines. Name the two properties he should add and what each will do.

MODEL ANSWERHe should use border-spacing, which specifies the distance between the borders of adjacent cells, so the cells no longer touch. He should also use padding, which specifies the space between the border and the content in a cell, so the text no longer sits against the border line.

I5. On a quiz form a student can tick all four answer options at once, but only one should be allowed. What is wrong and how would you fix it?

MODEL ANSWERThe options have been made using checkboxes, which allow the user to select one or more items. For a single choice, radio buttons should be used instead, and all four must be given the same name so they belong to one group. Only then can the user select just one option.
